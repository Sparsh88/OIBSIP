# PizzaNest Frontend Client

React.js (Vite) client application for the **OASIS INFOBYTE Level 3 Pizza Delivery Full-Stack Application**.

## Features
- **Modern Luxury Aesthetic**: Dark theme with rich ember accents, glassmorphic cards, and smooth CSS micro-interactions.
- **Interactive 4-Step Pizza Customizer**: Real-time visual pizza stage layering crusts, sauces, cheeses, and vegetable toppings with dynamic pricing.
- **Real-Time Live Order Tracking**: Socket.IO powered synchronization updating order status without page reloads.
- **Razorpay Test Payment Gateway**: Test mode checkout and secure backend signature verification.
- **Full Role-Based Dashboards**: Customer portal and dedicated Admin kitchen operations dashboard.

## Running Locally
```bash
# Install dependencies
npm install

# Start Vite Development Server
npm run dev
```
Accessible at: `http://localhost:5173`
